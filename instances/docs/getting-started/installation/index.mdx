# Mod Installation

:::warning[Compatibility Warning]
Modding support in Spaceflight Simulator (SFS) is primarily designed for the PC version of the game.
While asset mods (such as texture packs, part packs and planet packs) are supported on mobile versions (Android only as of 1.6.0.3), code mods (DLL mods) are only supported on the PC version due to platform limitations.
:::

:::info[DLC Requirements]
Mobile versions require the full expansion bundle to use mods.
This can either be done by purchasing each DLC individually or by purchasing the "Full Bundle".
Steam versions do not require any any DLCs to use mods, because all expansions are included with the base game on Steam when purchased.

Prices for the game and expansions may vary by region and platform.
:::

There are 4 types of mods as mentioned in the [introduction](/), code mods, texture packs, part packs, and custom solar systems (planet packs). The installation process for each type of mod is slightly different but is generally straightforward and the same across all supported platforms (Windows, macOS, and Android).

## Game Folder Locations

Before installing mods, you need to locate the game folder where SFS is installed. The location of the game folder varies depending on the platform:

- **Windows**: The game folder is typically located at `C:\Program Files (x86)\Steam\steamapps\common\Spaceflight Simulator\Spaceflight Simulator Game` or, depending on your installation.
- **macOS**: The game folder is typically located at `~/Library/Application Support/Steam/steamapps/common/Spaceflight Simulator/Spaceflight Simulator Game`.
- **Android**: The game folder is typically located at `/storage/emulated/0/Android/media/com.StefMorojna.SpaceflightSimulator`.
  - Note that root user is no longer required to access the SFS game folder on Android as of SFS 1.6.0. You can use a regular file manager app to navigate to the SFS game folder.

## Finding Mods

You can find authorised mods from the [SFS Forums](https://jmnet.one/sfs/forum/index.php?forums/game-mods.144/).

You can also find mods informally shared on other platforms such as the:

- <a href={`${site_config.socials.discord}`}>Modding Discord</a>
- <a href={`${site_config.socials.sfsOfficialDiscord}`}>Official SFS Discord</a>
- <a href={`${site_config.socials.sfsReddit}`}>SFS Subreddit</a>

Additionally, mod creators may share their mods on their own websites or GitHub repositories.
